MISSION 02 / PRACTICAL CHALLENGE

💻 Build Your Own Mini Webpage

Imagine that you are creating a personal webpage for a school project. Your webpage should introduce you and share some of your interests.

Your Mission

  1. Create a new file named mywebpage.html.
  2. Add the basic HTML document structure.
  3. Write a heading that introduces yourself.
  4. Add a paragraph about your hobbies or interests.
  5. Create an unordered list of three favorite things.
  6. Add a link to a useful educational website.
  7. Save the file and open it in your browser.

Starter Code

mywebpage.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My Personal Webpage</title>
</head>
<body>
    <h1>Hello! I'm a Future Web Developer</h1>

    <p>Welcome to my personal webpage!</p>

    <h2>My Favorite Things</h2>
    <ul>
        <li>Favorite hobby</li>
        <li>Favorite food</li>
        <li>Favorite subject</li>
    </ul>

    <a href="https://www.w3schools.com/html/">
        Learn More About HTML
    </a>
</body>
</html>

Challenge: Replace the sample text with your own information. Try changing the heading, adding another list item, and including an image.
