MISSION 01

HTML: Build the Structure

HTML stands for HyperText Markup Language. It gives a webpage its structure and organizes its content.

index.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Website</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>Welcome to my website!</p>
</body>
</html>

Important HTML Tags

  • <h1> creates a main heading.
  • <p> creates a paragraph.
  • <a> creates a link.
  • <img> displays an image.
  • <body> contains the visible webpage content.
  • <title> sets the browser tab title.

MISSION 02

CSS: Design Your Suit

CSS stands for Cascading Style Sheets. It controls the colors, fonts, spacing, and layout of your webpage.

style.css 
body {
    background-color: #101522;
    color: #ffffff;
    font-family: Arial, sans-serif;
}

h1 {
    color: #e62429;
}

p {
    font-size: 18px;
}

What Do These CSS Properties Do?

  • background-color changes the background color.
  • color changes the text color.
  • font-family changes the font.
  • font-size changes the text size.

MISSION 03

HTML Links: Swing to Another Page

The anchor tag creates a clickable link that takes visitors to another page or website.

links.html 
<a href="https://example.com">
    Visit This Website
</a>

The href attribute specifies the destination of the link.

MISSION 04

HTML Attributes: Give Elements More Information

HTML attributes provide additional information about an element. They are usually written inside the opening tag. An attribute often has a name and a value.

attributes.html 
<a href="https://www.w3schools.com">
    Learn HTML
</a>

<img src="images/coding.jpg"
     alt="A computer displaying code"
     width="300">

Understanding the Attributes

  • href specifies the destination of a link.
  • src specifies the location of an image.
  • alt provides a text description of an image.
  • width specifies the displayed width of an image.

Remember: The image example uses images/coding.jpg as an example path. You must provide that image in your project for it to display.

MISSION 05

HTML Lists: Organize Your Ideas

HTML lists help organize related information. There are two common types of lists.

1. Unordered List

An unordered list displays items with bullet points. Use <ul> and <li>.

unordered-list.html 
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

2. Ordered List

An ordered list displays items in a numbered sequence. Use <ol> and <li>.

ordered-list.html 
<ol>
    <li>Open a text editor.</li>
    <li>Write your HTML code.</li>
    <li>Save the file as index.html.</li>
</ol>

MISSION 06

Understand the HTML Document Structure

Every basic HTML document follows a structure that helps browsers understand and display the webpage correctly.

  • <!DOCTYPE html> declares that the document uses HTML5.
  • <html> contains the entire HTML document.
  • <head> contains document information and links to resources such as CSS.
  • <title> sets the browser tab title.
  • <body> contains the webpage's visible content.

Quick Review

HTML creates the structure, CSS controls the appearance, and JavaScript can make a webpage interactive.
